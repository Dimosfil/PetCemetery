# Архитектура Pet Cemetery

## Компоненты

- Next.js обслуживает адаптивный интерфейс и серверные HTTP-маршруты.
- PostgreSQL хранит пользователей, связи дружбы, мемориалы, церемонии, знаки памяти и жалобы.
- Локальный persistent volume хранит фотографии MVP; граница хранения позволяет
  позднее подключить S3-совместимый адаптер.
- Leaflet отображает карту, а поставщик тайлов выбирается через окружение.

## Границы безопасности

- Пароли хешируются bcrypt и никогда не возвращаются клиенту.
- Авторизационная cookie подписана, `httpOnly`, `sameSite=lax` и `secure` в production.
- Все SQL-запросы параметризованы.
- Запрос дружбы уникален для неупорядоченной пары пользователей; принять или отклонить его может только получатель, отменить — только отправитель, удалить принятую связь — любой участник.
- Загрузка принимает только JPEG, PNG и WebP размером до 5 МБ и сверяет заявленный MIME-тип с сигнатурой содержимого файла.
- Сервер проверяет владельца перед изменением или удалением мемориала.
- Публичная проекция данных не содержит точных координат для approximate/hidden.
- Секреты поступают только из окружения хоста.
- Google OAuth использует Authorization Code flow, одноразовые `state` и PKCE,
  серверный обмен кода и проверку подписи, issuer, audience и подтверждённого
  email в ID token. OAuth-токены не сохраняются в базе данных.

## Развёртывание

Docker Compose содержит приложение и локальную PostgreSQL для разработки.
На хостинге приложение может использовать внешнюю PostgreSQL через `DATABASE_URL`;
в этом случае сервис `db` можно убрать из deployment-конфигурации без изменения
приложения.
Контейнер публикует `/api/health`, который возвращает успех только при доступной
PostgreSQL; кратковременные DNS-сбои до подключения повторяются ограниченное
число раз перед ошибкой запуска или запроса.
