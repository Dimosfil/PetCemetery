# Pet Cemetery

Pet Cemetery — адаптивная социальная сеть памяти об ушедших домашних животных.
Пользователь может создать мемориал питомца, выбрать реальное, приблизительное,
символическое или скрытое место, провести виртуальную церемонию и принимать
памятные знаки от других людей.

## MVP

- регистрация и авторизация;
- личный кабинет владельца;
- необязательный публичный город владельца, независимый от точки мемориала;
- поиск авторизованных пользователей по городу, запросы и список друзей;
- создание и редактирование мемориала питомца;
- загрузка основной фотографии;
- публичная карта мемориалов;
- управляемая владельцем приватность координат;
- виртуальная церемония, свечи, цветы и памятные сообщения;
- жалобы как основа модерации.

Unity-приложение не входит в этот проект и остаётся отдельной задачей в бэклоге.

## Быстрый запуск через Docker

1. Скопируйте `.env.example` в `.env`.
2. Задайте уникальные `POSTGRES_PASSWORD` и `SESSION_SECRET`.
3. Выполните:

```powershell
docker compose up --build
```

После успешного запуска приложение доступно на `http://localhost:3000`.
Для HTTPS-развёртывания задайте `COOKIE_SECURE=true`; локальный Compose по HTTP
использует `false`.

## Локальная разработка

```powershell
npm install
npm run db:migrate
npm run dev
```

Для подключения к внешней PostgreSQL задайте `DATABASE_URL` только через
переменные окружения или секреты хостинга. Не добавляйте строку подключения в
Git, клиентский JavaScript или Docker-образ.

## Карта

Клиент карты не связан с конкретным поставщиком тайлов. URL и атрибуция задаются
через `NEXT_PUBLIC_TILE_URL` и `NEXT_PUBLIC_TILE_ATTRIBUTION`. Стандартные
публичные тайлы OpenStreetMap подходят для разработки и малой закрытой проверки,
но перед публичным запуском нужен поставщик с подходящими условиями и лимитами.

## Google OAuth

Вход и регистрация через Google включаются, когда серверу заданы `APP_URL`,
`GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET`. Секрет клиента нельзя добавлять в
Git или в переменные `NEXT_PUBLIC_*`.

Для локального запуска укажите `APP_URL=http://localhost:3000` и добавьте в
Google Cloud Console следующий Authorized redirect URI:

```text
http://localhost:3000/api/auth/google/callback
```

Для production добавьте отдельный URI с публичным HTTPS origin и задайте этот
же origin в `APP_URL`, например `https://example.com/api/auth/google/callback`.
Если Docker-порт меняется через `APP_PORT`, значение `APP_URL` должно содержать
тот же внешний порт.
